## О проекте

**MyLauncher** — проект лаунчера Minecraft с упором на простой старт, понятные действия и аккуратное управление загрузками. Цель — собрать интерфейс, установку версий и обновления в одном месте, без лишней сложности для игрока.

> **Сейчас:** проект только начинается. Готового приложения и опубликованных сборок пока нет — перечисленные ниже возможности являются планом.

## Что хотим сделать

- Чистый, удобный интерфейс, в котором легко разобраться.
- Загрузка и установка выбранной версии с наглядным прогрессом.
- Понятное управление установленными версиями и профилями.
- Запуск игры и обновление лаунчера из официальных релизов.
- Ясные сообщения об ошибках и безопасное восстановление загрузки.

## План развития

Двигаемся небольшими проверяемыми шагами. Состав этапов может уточняться по мере разработки.

- [x] **Старт проекта:** описание, направление и основа визуального стиля.
- [ ] **Интерфейс:** главный экран, навигация и состояния загрузки.
- [ ] **Загрузки:** выбор версии, загрузка, прогресс, отмена и понятные ошибки.
- [ ] **Управление игрой:** список установок, запуск и обновление.
- [ ] **MyLauncher 1.0:** первый стабильный публичный релиз с инструкцией и опубликованными сборками.

## Релизы

Когда появится готовая сборка, её можно будет найти во вкладке [Releases](https://github.com/professionalarduino-max/MyLauncher/releases). Пока приложение не выпущено — следите за планом и обновлениями в репозитории.

## Разработка

На текущем этапе репозиторий закладывает основу проекта. Технический стек и инструкции по сборке будут добавлены вместе с исходным кодом приложения.

## Безопасность

Мы хотим, чтобы источник каждой загрузки был понятен, а ошибки не приводили к потере данных. Не публикуйте в issues, обсуждениях и коммитах пароли, токены или другие секреты.
